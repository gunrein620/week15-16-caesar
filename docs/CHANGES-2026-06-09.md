# 작업 기록 — 2026-06-09

이 세션에서 진행한 변경 전체 정리. 영역별로 묶음.

## 1. 식단 이미지 파이프라인 (apps/mcp-server)

- **주간 OCR 연도 버그 수정** — 주간 식단표 이미지엔 연도가 없어 OCR이 2020 등으로 잘못 채우던 것을, 현재 기준 가장 가까운 해로 보정(`correctWeekStartYear`). (`tools.ts`)
- **이미지 매칭 정리** — 주간 동기화는 텍스트만 갱신하고 기존 끼니별 이미지를 보존하도록 `preserveExistingImage` 플래그 추가. 지난 날짜는 슬랙 임포트가 끼니별 실제 사진을 매핑. (`tools.ts`)
- **당일 수집 창 확대** — 절전 등으로 늦게 보충 실행돼도 그날 끼니를 잡도록 체크 창을 넓힘(점심 11:00–13:30, 저녁 17:00–19:30). (`tools.ts`, `tools.test.ts`)
- **OpenAI OCR 에러 가시화** — 실패 시 응답 본문까지 출력. (`tools.ts`)
- **env 자동 로드** — 모든 sync/유틸 스크립트가 루트 `.env`를 스스로 읽음(`process.loadEnvFile`). (`sync-weekly-menu.ts`, `sync-daily-menu.ts`, `import-slack-meals.ts`)
- **슬랙 임포터 경로 버그 수정** — `SLACK_MEAL_STORAGE_DIR` 상대경로를 cwd가 아닌 레포 루트 기준으로 해석. (`slack-meal-importer.ts`)
- **신규 유틸 스크립트** — `inspect-menus`(DB 점검), `clear-weekly-images`(주간표 이미지 비우기), `cleanup-bad-weekly`(2020 행 삭제), `reset-auth`(계정 전체 삭제), `sync-daily-menu --force`(테스트용 강제 수집).

## 3. 식단 화면 (/menus)

- 주간 보기 스트립(월~토), 날짜 클릭 이동.
- 사진 없는 끼니는 🍽️ 이모지로 대체, 카드 높이 맞춤.
- 알레르기/기피 하이라이트 — 로그인 시 내 프로필 기준 메뉴 항목에 배지.
- 메뉴별 평점 요약 배지(그날 메뉴만 집계, `/api/menus/ratings?date=`).
- "이 메뉴 후기 쓰기" 버튼 → `/reviews/new?menu=` prefill.
- 그날 메뉴 후기 모아보기(`/api/menus/reviews?date=`).

## 4. 후기 (/reviews, /reviews/[id], /reviews/new)

- 목록 정렬(최신·별점순) + ★ 별점 시각화(`StarRating`).
- 작성 폼 별점 클릭 입력 + 메뉴명 자동완성 칩.
- 상세: 비슷한 후기(RAG), 이전/다음 후기 이동, 👍 도움돼요 반응.

## 5. 홈 (/)

- 최근 식단 사진 갤러리, 🏆 이번 주 베스트 후기.
- 홈 DB 조회량 축소(top-rated 500→300, 대표이미지 80→40).

## 6. 프로필 (/profile/food)

- 설정 즉시 미리보기 — 현재 칩 기준 오늘 메뉴 GOOD/CAUTION/AVOID 실시간 표시.
- 저장 후 메인으로 이동.

## 7. AI 추천 (/ai/recommend) — RAG 판단

- **LLM이 후기 본문 + 프로필을 근거로 직접 판단**(`gpt-4.1-mini`, chat/completions). 알레르기는 규칙(AVOID) 안전장치, 실패 시 규칙 폴백. (`judgeWithReviews`)
- 질문에서 날짜/요일 인식(오늘/내일/모레/어제/X요일). (`dateFromQuestion`)
- 내 진단 히스토리(과거 AgentRun) 표시.

## 8. 챗봇 (정글밥 몽키)

- 명확한 의도 외 자유 대화는 LLM이 오늘 메뉴 맥락으로 응답(`/api/ai/chat`).
